# ESP32-S3 N16R8 + STS3215 安全测试程序

这是 LumiLamp 项目的单舵机台架测试程序。默认舵机 ID 为 1、总线波特率为 1000000。

## 安全特性

- 上电不自动运动，并主动尝试关闭扭矩。
- 每次动作前必须成功读取位置、电压和温度。
- 测试电压只允许 9.0～13.0V。
- 温度达到 65℃时拒绝动作并卸力。
- 单条 `move` 命令最大只允许 ±10°。
- 目标位置限制在 0～4095。

## VS Code + PlatformIO

1. 用 VS Code 打开本文件夹。
2. 安装 PlatformIO IDE 扩展。
3. 点击底部工具栏的对勾进行编译。
4. ESP32-S3 用数据线连接电脑后，点击右箭头烧录；端口按设备管理器中的实际端口选择，不在工程中永久写死 COM 号。
5. 打开串口监视器，波特率为 115200。看到 `> ` 提示符后输入命令；输入字符会实时回显，支持退格。

如果自动烧录失败，按住开发板 `BOOT`，短按一次 `RST`，松开 `BOOT` 后重试。

## 命令

```text
ping
status
torque on
torque off
move 5
move -5
help
```

`move` 是相对当前位置的角度，不是绝对角度。首次测试只使用 `move 5` 和 `move -5`。

## 接线

- GPIO17（TX）→ URT-2 TXD
- GPIO18（RX）← URT-2 RXD
- ESP32 GND ↔ URT-2 GND
- ESP32 5V → URT-2 +5V（URT-2 USB-C 不接，避免双电源反灌）
- URT-2 电平开关置于 3V3
- URT-2 的 `DTR` 不接 ESP32
- 12V/3A 只为舵机侧供电，严禁接入 ESP32 GPIO/5V/3V3
